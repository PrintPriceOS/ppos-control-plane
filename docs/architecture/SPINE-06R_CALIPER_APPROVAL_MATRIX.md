### Inviolable Provenance & Manufacturing Release Guardrails
1. **No False `VERIFIED` Promotion**: Every variant reconciled from `paper_caliper_reference_library` is recorded with:
   - `caliper_source = 'LIVONIA_REFERENCE_IMPORT'`
   - `caliper_confidence_status = 'REFERENCE_IMPORTED'`
   - Never `VERIFIED`, never `MANUFACTURER_DATASHEET`, and never `MEASURED_MICROMETER`.
2. **Manufacturing Release Remains Blocked**: Because `caliper_confidence_status = 'REFERENCE_IMPORTED'` and profile certification tier is `MATH_BRANCH_VALIDATED`, Control Plane returns `canReleaseToManufacturing: false` and `POST /api/v1/spine/calculations/:id/verify-release` blocks autonomous release with `422 MANUFACTURING_RELEASE_BLOCKED_UNCERTIFIED_PROFILE`.
3. **Why Same GSM (100 gsm) Produces Distinct Spines**:
   - `G-Print 100 gsm` (`var_6ebb28170a7e23bd`, 64×90 cm FSC): `caliper_um = 98 µm` → 200 pages net block = `9.80 mm` → Glued Spine = `10.5 mm`, Sewn Spine (with 250g cover @ `225 µm`) = `11.5 mm`.
   - `Amber Graphic 100 gsm` (`var_7b7e3a2a2a4a0313`, 64×90 cm FSC): `caliper_um = 122 µm` → 200 pages net block = `12.20 mm` → Glued Spine = `13.0 mm`, Sewn Spine (with 250g cover @ `225 µm`) = `14.0 mm`.
